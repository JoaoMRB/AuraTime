# Self-hosted fonts

Latin subsets of variable fonts, downloaded from Google Fonts and distributed under the
[SIL Open Font License 1.1](https://openfontlicense.org/).

| File | Family | Copyright |
|---|---|---|
| `inter.woff2` | Inter | © The Inter Project Authors |
| `orbitron.woff2` | Orbitron | © The Orbitron Project Authors |
| `outfit.woff2` | Outfit | © The Outfit Project Authors |
| `playfair-display.woff2`, `playfair-display-italic.woff2` | Playfair Display | © The Playfair Project Authors |

They are served locally so the app, the browser extension and the canvas renderer
(USB screen) work offline and can wait on `document.fonts.ready`.
